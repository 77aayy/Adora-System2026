# 🔧 Scripts

هذا المجلد يحتوي على جميع السكريبتات المساعدة للمشروع.

## 📁 الملفات:

- `deploy.sh` - سكريبت النشر للأنظمة Unix/Linux/Mac
- `deploy.bat` - سكريبت النشر لأنظمة Windows
- `organize_files.ps1` - سكريبت PowerShell لتنظيم الملفات (تاريخي)

## 🚀 الاستخدام:

### Linux/Mac:
```bash
./scripts/deploy.sh
```

### Windows:
```cmd
scripts\deploy.bat
```
