# مراجعة فرونت إند — صفحة About Us (سنير فرونت إند)

## 1. الوصولية (A11y)

| البند | الحالة | التوصية |
|--------|--------|----------|
| **prefers-reduced-motion** | ❌ غير مطبّق | إيقاف أو تخفيف أنيميشن الرادار والـ pulse عند `prefers-reduced-motion: reduce` |
| **زر CTA "إرسال طلب تجربة"** | ⚠️ | إضافة `type="button"` و `aria-label` عند الحاجة (مثلاً للقارئ الشاشة) |
| **الرادار (ديكور)** | ⚠️ | إضافة `aria-hidden="true"` لأن المحتوى غير نصي وديكوري |
| **نموذج Trial Modal** | ❌ | ربط كل `<label>` بـ `htmlFor` و `id` على الـ input لتحسين التنقل والـ focus |
| **التباين** | ✅ | ألوان التيل والنص مناسبة في الوضعين الفاتح والداكن |

## إصلاحات مُنفّذة في هذا الالتزام

- إضافة دعم `prefers-reduced-motion` لأنيميشن الرادار والـ badge.
- إضافة `type="button"` و `aria-label` لزر الـ CTA.
- إضافة `aria-hidden="true"` لوعاء الرادار.
- ربط labels الـ modal بالـ inputs عبر `id` و `htmlFor`.
- تخفيف وتيرة تحديث الـ scan (مثلاً 100ms).
- إزالة أو تعليق CSS الميت المرتبط بالرادار القديم (إن وُجد).
