# 🔄 دليل التزامن مع GitHub

## ⚠️ قاعدة مهمة: **التحقق أولاً قبل العمل**

قبل البدء بأي عمل على المشروع، يجب التحقق من وجود تحديثات على GitHub.

---

## 🚀 الطريقة السريعة (مستحسنة)

### 1. قبل البدء بالعمل:

```powershell
# في PowerShell
.\git-sync-check.ps1
```

أو يدوياً:

```bash
git fetch origin main
git status
```

### 2. إذا كانت هناك تحديثات:

```bash
# حفظ التغييرات المحلية (إن وجدت)
git stash

# سحب التحديثات
git pull origin main

# استعادة التغييرات المحلية (إن وجدت)
git stash pop
```

---

## 📋 سير العمل الموصى به

### عند بدء جلسة عمل جديدة:

1. **افتح Terminal/PowerShell**
2. **تحقق من التحديثات:**
   ```bash
   git fetch origin main
   git status
   ```
3. **إذا كانت هناك تحديثات:**
   - سحب التحديثات أولاً
   - ثم البدء بالعمل
4. **إذا كانت النسخة محدثة:**
   - ابدأ العمل مباشرة

---

## 🔔 تذكير تلقائي

**قبل أي تعديل في الكود، سأقوم تلقائياً بـ:**

1. ✅ التحقق من التحديثات (`git fetch`)
2. ✅ عرض آخر commits من GitHub
3. ✅ سحب التحديثات إذا كانت موجودة
4. ✅ ثم البدء بالعمل

---

## 🛠️ أوامر مفيدة

### التحقق من التحديثات:
```bash
git fetch origin main
git log HEAD..origin/main --oneline
```

### سحب التحديثات:
```bash
git pull origin main
```

### رؤية الفرق:
```bash
git diff HEAD origin/main
```

### عدد التحديثات:
```bash
git rev-list --count HEAD..origin/main
```

---

## ⚡ اختصار سريع

```bash
# تحقق وسحب في أمر واحد
git fetch origin main && git pull origin main
```

---

## 📝 ملاحظات

- **لا تعمل على نسخة قديمة** - دائماً تحقق أولاً
- **احفظ عملك** - استخدم `git stash` قبل pull
- **تحقق من Conflicts** - بعد pull، تحقق من وجود تعارضات

---

**قاعدة ذهبية:**
